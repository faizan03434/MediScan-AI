# Dataset expansion and the >97% target — 10 October 2026

The target is a development objective, not a measured result or a guarantee. None of the current artifacts has independently established >97% clinical performance. The conjunctivitis pilot's 97.92% score is an internal image-level balanced accuracy from 46 images, not external patient-level validation. Latest tongue/posture updates are in [TONGUE_POSTURE_PROGRESS.md](TONGUE_POSTURE_PROGRESS.md): a truthful TongueDx permission inquiry is now submitted; open MultiPosture data is acquired and a subject-disjoint sitting classifier trained. Tongue-coating acquisition is ongoing and Dryad file downloads currently require authentication/return 403.

## Training and evaluation

1. Record original source, consent/license terms, modality, actual independent subjects, labels and acquisition conditions. Quarantine unverified labels/rights and incompatible image types.
2. Deduplicate decoded pixels, review near duplicates and group all related views/visits by verified subject. Freeze a separate external test cohort before model selection; do not use it for hyperparameter search.
3. Improve ROI capture, lighting/blur quality checks and architectures using training/validation data only. Wound U-Net adds encoder/decoder context and matched image/mask flips at the same 96×96 resolution as the previous baseline; its validation cohort is already reused and is not new external evidence.
4. Report balanced accuracy, per-class sensitivity/specificity and confusion matrices for classification; Dice/IoU for masks; physical measurement error for size/pose. Calibration, rejection of unfamiliar conditions and device/skin-tone/site subgroup performance are separate requirements.
5. `training/evaluate_quality_target.py` recomputes classification metrics from confusion counts, checks checkpoint integrity and requires supplied external/patient/ground-truth evidence. Classification additionally requires every class recall/specificity confidence lower bound to exceed 97%, using approximate Wilson bounds with Bonferroni adjustment across those proportions ([NIST formula](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm)). This assumes independent patient observations; repeated images cannot be counted as independent trials. A perfect 46-image test still fails this uncertainty check. Validation Dice is not substituted for test Dice. Passing this numerical check never authorizes clinical deployment or proves the evidence authentic; segmentation uncertainty, clustering and independent clinical review remain required.

No result below the target will be renamed, rounded upward or presented as >97%. No model is enabled for diagnosis merely because it exceeds a small internal test score.
